# 🚀 SpaceShooter2D

**SpaceShooter2D** est un jeu 2D simple développé avec **Unity**, dans le cadre de la formation **MakeYourGame**.  
Ce projet a pour but de se **familiariser avec Unity**, son interface, ses composants de base, et la logique de gameplay.

---

## 🎯 Objectif

Découvrir les bases de Unity à travers un projet de **shoot'em up 2D** :
- Prise en main de l’éditeur Unity
- Scripts en C#
- Physique et collisions
- Prefabs, scènes et UI
- Gestion du projet avec Git

---

## 🛠️ Technologies

- **Unity** (version recommandée : 2022.x ou équivalent)
- **C#**
- **Git / GitHub**
